v1 Screens

The four screens of the first playable slice, in the order a player meets them: look at the Star System, plan a Hop, watch it fly, read the report. Drawn at the game's native 640×360 with the real UI kit. Planets, Moons, the star and the Spacecraft are stand-ins labelled with the sprite key that replaces them. Every number is an example, not tuned gameplay.

To change a layout, edit docs/design/v1-screens.html: positions are native pixels, and the comment at the top of the file explains the parts.

4 · Hop report

Every Hop ends here. The report compares each burn's estimate with what really happened and explains the outcome in plain words. Three variants: Arrived, Fell Short, Crashed.

Arrived

Fell Short

Crashed

  1. 1Outcome. Arrived in green, Fell Short or Crashed in red. Always with an icon and the word, never colour alone.
  2. 2Estimate against actual. Every burn, with the difference in percent. A burn that never happened says so.
  3. 3Margin left, or shortfall. How much spare Δv was left, or how much was missing.
  4. 4Why. One or two plain sentences naming the burn that decided the outcome, with the numbers.
  5. 5Lesson. A short mission-design takeaway, such as why margins matter.
  6. 6Next step. Continue returns to the map on the new Body. New Run starts a fresh Star System (Spec C replaces it with the full end-of-Run screen).
