Notes

How parts could map to the game

  • Core = the Chassis picked at New Run.
  • Side propulsors and main engine = the Engine Component: a better Engine adds nacelles or boosters.
  • Components show on the hull when installed: Drill, Radar, Jump Drive, Comms.
  • The game assembles each ship from part sprites at runtime, so it needs no art per combination.

Ground

  • A flat strip seen from the side, with a straight top edge the ship stands on, like a 2D side-view game.
  • No perspective, no curve and no planet texture. Stones are seen in cross-section.
  • "Far ridges" adds one distant silhouette behind it. The default is sky only.
