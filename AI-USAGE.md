# AI usage disclosure

Space Apps 2026 requires every submission to describe how AI ("Super Intelligence", SI) was used, and to acknowledge SI-generated code and data in text and metadata. This file is that acknowledgement and is kept current by the agents.

## Idea and design

The game's concept, design direction and every product decision come from the human team. AI acted as an interviewer: it asked questions, stress-tested the human's ideas, researched facts, and wrote the agreed decisions down as specs (`spec`-labelled GitHub issues) and glossary entries. AI did not originate the game idea.

## Code

Nearly all source code is written by AI agents (Anthropic Claude via Claude Code), working from human-approved specs:

- **Orchestrator / Planner / Reviewer:** Claude Opus. **Builders / Researchers:** Claude Sonnet (Opus for complex tickets, Haiku for small ones).
- Every AI-authored commit carries a `Co-Authored-By: Claude …` trailer naming the model, so `git log` is the per-commit record.
- Every change was reviewed by an AI Reviewer agent and verified by automated tests and CI before merging.

## Data

Real-world mission data (launch vehicles, orbits, subsystem figures) is gathered by AI Researcher agents from primary sources (NASA and other agency/provider publications), recorded with citations in `docs/research/`, and referenced by a `source` field in the game's data modules.

## Art, audio and media

Almost all art is AI-generated pixel art (the exceptions are marked below; see `docs/adr/0004-ai-generated-art-with-visible-watermark.md`):

- **UI kit** (`public/assets/ui/`): frames, buttons, bars, icons and cursors, generated with AI by the human team.
- **Game sprites** (`public/assets/sprites/`): star, planets, Moons, Spacecraft and extra icons, generated by AI agents (Claude) in the kit's palette and style, from a script kept in `docs/design/sprites/`.
- **Chassis sprites** (Chassis: `public/assets/sprites/chassis_scout`, `chassis_hauler`, `chassis_lancer` and the `fx_thruster` plume, issue #21; all generated): the human team's rough scene sketches in `docs/design/drawings/` set the composition only. AI agents (Claude) generate the three Chassis (since issue #135 the interim upright ships Herald Mk II, Bastion and Lancer, drawn by `docs/design/sprites/gen_ships.py`, a Python port of the AI-written shipwright mockup `docs/design/shipwright-bench.html`; since issue #232 each atlas holds the Chassis art and every Component art (Engine, Fuel Tank pod, Drill arm, Radar dish, Jump Drive ring) at every mount point, in landed, landed-with-lights-on and flight frames, and the game composes the drawn Spacecraft from them; the Fuel Tank pod is the one piece the mockup lacks, drawn with its primitives; the generator also writes the mount and nozzle data `src/game/assets/chassisArt.json`; contact sheet in `docs/design/chassis-preview.png`) as original pixel art in the kit's palette. The ground strips (`public/assets/sprites/surface_moon`, `surface_rocky`, `surface_icy`, issue #132; flat side-view, 800x64, stones in cross-section) are generated art too: AI agents (Claude) wrote the generator section in `docs/design/sprites/gen_sprites.py` that draws them in the kit's palette (preview in `docs/design/surfaces-preview.png`). Agent-written code (`src/game/scenes/groundArt.ts`) still paints a similar flat strip (irregular stones in the same kit ramps) at runtime as a stand-in whenever the strip is absent from the manifest. The [Voxel Spaceships](https://maxparata.itch.io/voxel-spaceships) pack (CC BY-ND 4.0) was a style reference only for the earlier voxel-style ships: nothing was traced, converted, rendered, recoloured or shipped from it, and those ships are gone.

- **Heliopause sprite** (`public/assets/sprites/body_heliopause`, issue #166; AI-drawn): an AI agent (Claude) wrote the generator section in `docs/design/sprites/gen_sprites.py` that draws this 64x64 ring of faint violet light (kit palette `vi0`-`vi4`) for the edge of the Star System, matching the Nav Chart's dashed Heliopause ring (preview in `docs/design/sprites-preview.png`). The on-screen "AI-generated art" label covers it (ADR 0004).
- **Approach Body sprites** (`public/assets/sprites/body_<kind>_<n>_approach`, 11 files, 256x256, issue #202; AI-drawn): AI agents (Claude) extended the generator in `docs/design/sprites/gen_sprites.py` so each Body variant's drawing (rocky planets, gas giants, Moons) is also made at 256x256, in the kit palette, for the Hop's Approach shot. They are the same per-variant drawings as the small sprites, scaled up, so each variant keeps its identity; re-running the script reproduces them byte for byte (contact sheet: `docs/design/approach-bodies-preview.png`). The on-screen "AI-generated art" label covers them (ADR 0004).

- **VFX sprites** (`public/assets/sprites/fx_explosion`, `fx_flame`, `fx_plume`, `fx_flash`, `fx_vent`, `fx_debris`, `fx_flare`; AI-drawn): an AI agent (Claude) wrote `docs/design/sprites/gen_vfx.py`, which draws an explosion, an engine fire, a takeoff exhaust plume, an ignition/impact flash, a Fuel-venting spray, scrap debris chunks and a solar-flare wave in the kit's palette, for the Takeoff and Landing (#201), the Cruise (#204) and the coming Cruise events (preview in `docs/design/sprites/vfx-preview.png`). The on-screen "AI-generated art" label covers them (ADR 0004).
- **Component icons** (`public/assets/sprites/comp_engine`, `comp_fuel_tank`, `comp_drill`, `comp_radar`, `comp_jump_drive`; AI-drawn): an AI agent (Claude) wrote `docs/design/sprites/gen_component_icons.py`, which draws the five 16×16 Component icons (gunmetal bodies, cyan for interactive parts, amber for Fuel, violet for the Jump Drive) in the kit's palette, matching the code-drawn stand-ins in `componentIconSet.ts` (#235; preview beside the stand-ins in `docs/design/sprites/component-icons-preview.png`). The on-screen "AI-generated art" label covers them (ADR 0004).
- **Particle sprites** (`public/assets/sprites/fx_dust`, `fx_smoke`, `fx_spark`, issue #98): NOT AI-generated art. The human designed the three pixel grids; `docs/design/sprites/gen_sprites.py` only encodes them verbatim into PNGs (kit palette `wh0`-`wh3`). Code tints them (dust and smoke per surface, sparks amber), and an AI agent (Claude) wrote that code and the smoke's motion settings.

- **Browser favicon** (`public/favicon.svg`, issue #102): a 16×16 pixel-art ringed planet in the kit's palette, drawn by an AI agent (Claude) from `docs/design/sprites/gen_favicon.py`. It only appears in the tab of the game page, whose permanent "AI-generated art" label covers it like every other generated sprite.

- **Music** (`public/assets/audio/`: "Abandoned Craft", two takes, `music_abandoned_craft_1.mp3` and `music_abandoned_craft_2.mp3`; "Jagged Pulse", two tense takes, `music_jagged_pulse_1.mp3` and `music_jagged_pulse_2.mp3`; issue #203): AI-generated by the human team with [Suno](https://suno.com) (free plan, non-commercial use, credited in Credits & References). The human wrote the prompt and chose the takes.

As the rules require, every game screen shows a visible "AI-generated art and music" watermark. No fonts are AI-generated.

## NASA branding

No NASA logos, insignia, flags or mission identifiers are used.
