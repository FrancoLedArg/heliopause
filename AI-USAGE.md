# AI usage disclosure

Space Apps 2026 requires every submission to describe how AI ("Super Intelligence", SI) was used, and to acknowledge SI-generated code and data in text and metadata. This file is that acknowledgement and is kept current by the agents.

## Idea and design

The game's concept, design direction and every product decision come from the human team. AI acted as an interviewer: it asked questions, stress-tested the human's ideas, researched facts, and wrote the agreed decisions down as specs (`spec`-labelled GitHub issues) and glossary entries. AI did not originate the game idea.

## Code

Nearly all source code is written by AI agents (Anthropic Claude via Claude Code), working from human-approved specs:

- **Orchestrator / Planner / Reviewer:** Claude Opus. **Builders / Researchers:** Claude Sonnet (Opus for complex tickets).
- Every AI-authored commit carries a `Co-Authored-By: Claude …` trailer naming the model, so `git log` is the per-commit record.
- Every change was reviewed by an AI Reviewer agent and verified by automated tests and CI before merging.

## Data

Real-world mission data (launch vehicles, orbits, subsystem figures) is gathered by AI Researcher agents from primary sources (NASA and other agency/provider publications), recorded with citations in `docs/research/`, and referenced by a `source` field in the game's data modules.

## Art, audio and media

All art is AI-generated pixel art (see `docs/adr/0004-ai-generated-art-with-visible-watermark.md`):

- **UI kit** (`public/assets/ui/`): frames, buttons, bars, icons and cursors, generated with AI by the human team.
- **Game sprites** (`public/assets/sprites/`): star, planets, Moons, Spacecraft and extra icons, generated by AI agents (Claude) in the kit's palette and style, from a script kept in `docs/design/sprites/`.
- **Chassis sprites and landscape surfaces** (surfaces: `public/assets/sprites/surface_*`, issue #22; Chassis: `public/assets/sprites/chassis_scout`, `chassis_hauler`, `chassis_lancer` and the `fx_thruster` plume, issue #21; all generated): the human team's rough scene sketches in `docs/design/drawings/` set the composition only. AI agents (Claude) generate the three Chassis (each a spritesheet of landed, landed-with-lights-on and flight frames, drawn as voxel-style ships by a small renderer in `docs/design/sprites/gen_sprites.py`, preview in `docs/design/chassis-preview.png`) and the landscape surfaces (three parallax layers each for Rocky, Moon and Icy Bodies, preview in `docs/design/surfaces-preview.png`) as original pixel art in the kit's palette. The [Voxel Spaceships](https://maxparata.itch.io/voxel-spaceships) pack (CC BY-ND 4.0) is a style reference only: nothing is traced, converted, rendered, recoloured or shipped from it.

- **Browser favicon** (`public/favicon.svg`, issue #102): a 16×16 pixel-art ringed planet in the kit's palette, drawn by an AI agent (Claude) from `docs/design/sprites/gen_favicon.py`. It is a browser tab icon, not a game screen, so it carries no watermark.

As the rules require, every game screen shows a visible "AI-generated art" watermark. No audio or fonts are AI-generated so far; any that are will be listed here.

## NASA branding

No NASA logos, insignia, flags or mission identifiers are used.
